# 테스트

게임을 고친 뒤 기존 기능이 망가지지 않았는지 브라우저로 직접 열어 확인하는 스크립트들이다.
실제 시각 대신 원하는 시각으로 시계를 고정해서 돌린다 (점심 12시, 밤 10시 등).

## 준비

```bash
npm install playwright          # 한 번만
npx playwright install chromium # 브라우저가 없을 때만
```

이미 설치된 크롬/크로미움을 쓰려면 `CHROMIUM` 환경 변수에 실행 파일 경로를 넣는다.

## 돌리기

```bash
node tests/run-all.js      # 전부
node tests/reach.js        # 하나만
```

| 파일 | 확인하는 것 |
|---|---|
| `smoke.js` | 출근해서 모든 층을 돌아도 오류가 없는지 |
| `reach.js` | 가구를 옮겨도 자리·계산대·퇴식구 등에 갈 수 있는지, 새로 막힌 칸이 없는지, 서버실엔 남박사가 못 들어가는지 |
| `sprites.js` | 모든 캐릭터 그림이 틀 밖으로 잘리지 않는지 |
| `cafeteria.js` | 지하 식당 직원이 한가하면 쉼터, 손님이 오면 제자리 · 손님은 계산 → 배식 → 자리 |
| `lab5.js` | 5층 조명 스위치 · 메모 보드 크게 보기 · 밤 충전 청소기 · 화면 밖에 있다 돌아왔을 때 시각 맞추기 |
| `backup.js` | 백업 내보내기에 기록 전부가 담기고 불러오면 되살아나는지 |

## 배포할 때

`assets/` 파일을 고치면 `index.html` 안의 `?v=날짜` 꼬리표를 모두 새 값으로 바꾼다.
아이패드 사파리가 예전 파일을 붙잡고 있지 않게 하려는 것이다.
