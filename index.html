이용 가이드

손그림 스타일 사무실에서 16명의 직원들이 실제 시각에 맞춰 출퇴근하는 방치형 게임이에요. 화면을 켜두기만 해도 하루 일과가 흘러가고, 직접 말을 걸거나 회사를 운영할 수도 있어요.

하루 사이클 — 그냥 지켜만 봐도 재밌어요

시각무슨 일이 일어나나
09:00입구에서 직원들이 순서대로 걸어나와 각자 자리로 출근해요
12:00실장이 "점심시간입니다."라고 말한 뒤, 전 직원이 줄지어 나가요
13:00다시 순서대로 들어오는데, 맨 앞 직원이 "배부르다."라고 말해요
18:00전 직원이 퇴근해요
  • 페이지를 몇 시에 열든 상관없어요 — 지금이 근무시간이면 이미 출근해있는 상태로 떠요
  • 근무 중엔 가끔 직원이 "졸리다", "야근확정" 같은 혼잣말을 랜덤으로 중얼거려요
  • 날씨는 맑음/비가 랜덤으로 바뀌는데, 맑은 날이 훨씬 많아요 (15:1 비율)
  • 밤 시간대(19시~7시)나 야근모드일 땐 창문만 어두워져요

버튼 기능

버튼하는 일
주요 프로젝트회사가 추진 중인 사업을 등록/관리
야근모드전원 퇴근 후 랜덤 2~4명만 남아 야근. 다시 누르면 복귀
전체 미리보기시간과 상관없이 전 직원을 한 번에 불러옴
설정명패·팀·직원 이름 변경, 제작자 정보 보기
회의랜덤 6명이 회의실로 이동, 10초 후 복귀
탕비실랜덤 2명이 탕비실에서 짧은 잡담 후 복귀
메일 보내기랜덤 직원이 내용을 일부만 읽고 반응

주요 프로젝트 — 오래 켜둘수록 보람있는 기능

  • 추가 → 사업명/기간/내용/예산 입력 → 저장 (최대 10개)
  • 선택 → 항목 체크 → 삭제로 제거 가능
  • 7분마다 등록된 사업 중 하나가 랜덤으로 완료 처리돼요 (순서 무관)
  • 완료되는 순간 전 직원이 동시에 "프로젝트 완료!"를 외쳐요
  • 10개를 전부 완료하는 걸 보려면 화면을 약 70분 켜두면 돼요
등록한 사업 목록은 저장되어 새로고침해도 남아있지만, 7분 타이머는 페이지를 새로 열 때마다 다시 시작돼요.

직접 참여하기 — 명령어로 말 걸기

입력창에 /직원이름 하고싶은말 형식으로 입력해보세요.
예시: /이노트 배고파

  • 이름 대신 직책으로도 부를 수 있어요 (예: /실장 퇴근하고싶다)
  • 이름과 문장 사이 띄어쓰기가 없어도 알아서 인식해요
  • 자리에 없는 직원을 불러도 잠깐 등장해서 대답해줘요

즐기는 팁

  • 그냥 켜두고 하루 사이클만 구경해도 소소한 재미가 있어요
  • 명령어로 직원들에게 말 걸며 놀아보세요
  • 사업을 몇 개 등록해두고 다른 일 하다가, 가끔 돌아와서 "프로젝트 완료!" 외치는 걸 확인하는 재미가 쏠쏠해요
  • 야근모드는 시간과 무관하게 언제든 눌러서 분위기를 바꿀 수 있어요
